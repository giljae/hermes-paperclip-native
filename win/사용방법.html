Hermes + Paperclip 사용 방법

이 컴퓨터에 설치된 AI 회사(Hermes + Paperclip)를 관리하는 방법입니다.

1. 한 줄로 설치하기

PowerShell 창을 열고(시작 메뉴에서 PowerShell 검색) 아래 한 줄을 붙여 넣습니다. 관리자 권한은 필요하지 않습니다.

irm https://github.com/giljae/hermes-paperclip-native/releases/latest/download/bootstrap.ps1 | iex

실행 정책 때문에 막히면 다음 한 줄을 먼저 실행한 뒤 다시 시도합니다.

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

2. Windows Defender 안내

Defender가 uv.exe를 바이러스로 잘못 인식해 격리할 수 있습니다(알려진 오탐). 설치 중 파일이 사라지거나 uv 명령을 찾을 수 없다는 오류가 나면, Windows 보안 → 바이러스 및 위협 방지 → 제외에 설치 폴더 (%LOCALAPPDATA%\hermes-paperclip-native)를 추가한 뒤 다시 실행해 주세요.

3. 관리 파일

%USERPROFILE%\HermesPaperclip 폴더에 관리용 파일이 있습니다. 더블클릭하면 됩니다.

  • 시작.cmd — 서버를 켭니다.
  • 중지.cmd — 서버를 끕니다.
  • 상태.cmd — 실행 상태와 대시보드 주소를 봅니다.
  • AI연결.cmd — AI(모델)를 연결합니다.
  • 업데이트.cmd — 최신 버전으로 올립니다.
  • 제거.cmd — 설치를 지웁니다.

4. 자동 시작 (로그인 시)

로그인할 때 자동으로 켜지도록 작업 스케줄러에 등록됩니다. 등록 여부는 다음으로 확인합니다.

schtasks /Query /TN hermes-paperclip

권한 문제로 작업 스케줄러 등록이 안 되면 설치기는 자동으로 백그라운드 실행으로 대체합니다(설치는 실패하지 않습니다).

5. 대시보드

서버가 켜지면 브라우저에서 http://127.0.0.1:3100 을 엽니다. 포트가 다르면 상태.cmd 가 알려주는 주소를 사용하세요.

6. 제거

제거.cmd 를 더블클릭하거나, PowerShell에서 아래를 실행합니다.

powershell -NoProfile -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\hermes-paperclip-native\app\<버전>\win\commands.ps1" uninstall
설치 전부터 쓰던 Hermes 설정(%USERPROFILE%\.hermes)은 그대로 둡니다.

7. 지원 버전

Windows 10 21H2 이상 / Windows 11 (64비트). 기본 내장된 Windows PowerShell 5.1 에서 동작합니다.
