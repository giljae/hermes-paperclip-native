Hermes + Paperclip 설치 안내

이 문서는 터미널을 잘 모르는 분을 위한 안내입니다. 순서대로만 따라 하시면 됩니다.

Windows 사용자라면 — 이 문서의 명령(curl / bash)은 macOS·Linux용입니다. Windows는 PowerShell 한 줄 명령을 쓰세요. 
irm https://github.com/giljae/hermes-paperclip-native/releases/latest/download/bootstrap.ps1 | iex
자세한 내용: Windows 설치 안내
먼저 알아두세요
  • 설치에는 인터넷이 필요하고, 10~30분 정도 걸립니다. 내려받는 양이 큽니다.
  • 관리자 암호는 한 번도 필요 없습니다. 암호를 물으면 잘못된 것입니다.
  • 진행되는 검은 창은 끝날 때까지 닫지 마세요.

설치 방법 권장 — 복사해서 붙여넣기

이 방법을 권합니다. 아래 한 줄을 복사해 터미널에 붙여넣고 Enter만 누르면 됩니다. macOS의 “확인되지 않은 개발자” 경고가 전혀 뜨지 않습니다.
  1. 터미널을 엽니다.
    Spotlight(⌘ + Space)를 열고 터미널을 입력한 뒤 Enter를 누르세요.
  2. 아래 한 줄을 복사(오른쪽 클릭 → 복사)합니다. 
    curl -fsSL https://github.com/giljae/hermes-paperclip-native/releases/latest/download/bootstrap.sh | bash
  3. 터미널 창을 한 번 클릭한 뒤 ⌘ + V 로 붙여넣고 Enter 를 누릅니다.
  4. 한국어로 진행 상황이 나옵니다. 끝날 때까지 기다리세요.
  5. 끝나면 브라우저가 자동으로 열리고 대시보드가 보입니다. 홈 폴더에 HermesPaperclip 폴더가 생깁니다 — 앞으로 켜고 끄고 지울 때 씁니다.

“한 줄짜리 스크립트를 인터넷에서 바로 실행하는 게 찝찝하다”면, 그 판단이 맞습니다. 그럴 때는 아래 방법으로 파일을 직접 받아 눈으로 확인한 뒤 실행하세요.

설치 방법 2 — 파일을 직접 받아서

이 방법은 macOS가 경고로 막습니다. 최신 macOS는 인터넷에서 받은 스크립트를 그냥 실행하지 못하게 합니다(서명이 없기 때문입니다). 아래 “막혔을 때” 절차가 필요합니다.
  1. 릴리스 페이지에서 HermesPaperclip-macOS.zip 을 내려받아 압축을 풉니다.
  2. 설치.command 를 우클릭 → 열기 합니다.
  3. “확인되지 않은 개발자” 창이 뜨고 열기 버튼이 없으면 → 시스템 설정 → 개인정보 보호 및 보안 으로 가서 아래쪽 “그래도 열기” 를 누른 뒤 다시 시도합니다.
    macOS 버전에 따라 이 단계가 없거나 이름이 다를 수 있습니다.
  4. 경고를 통과하면 검은 창에서 한국어 진행이 시작됩니다.

리눅스라면

아래 한 줄만 실행하면 됩니다. 관리자 암호가 필요 없습니다.

curl -fsSL https://github.com/giljae/hermes-paperclip-native/releases/latest/download/bootstrap.sh | bash

자세한 내용은 docs/linux.md 를 보세요. GUI가 없는 서버에서는 브라우저가 열리는 대신 주소만 출력됩니다.

설치가 끝난 뒤 — AI 연결

설치만으로는 AI가 연결되지 않습니다. HermesPaperclip 폴더의 AI연결을 실행하면 웹 설정 화면이 브라우저에 열립니다 (http://127.0.0.1:9119). 거기서 모델과 API 키를 연결하세요.

  1. 모델 화면에서 프로바이더와 모델을 고릅니다(Nous Portal 로그인 또는 API 키).
  2. 설정 화면에서 API 키를 넣습니다(Anthropic / OpenAI / OpenRouter 등).

브라우저가 자동으로 열리지 않으면 터미널에 표시된 주소를 직접 여세요.

문제가 생겼을 때

  • “확인되지 않은 개발자”로 막힐 때 — 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기. 또는 위의 설치 방법(한 줄) 를 쓰세요.
  • 진행이 멈춘 것 같을 때 — 실제로는 내려받는 중일 수 있습니다. 30분까지 기다려 보세요.
  • 다시 시도할 때 — 같은 명령을 다시 실행하면 됩니다. 이미 된 단계는 건너뜁니다.
  • 기록을 보내야 할 때 — ~/.hermes-paperclip-native/logs/ 폴더의 파일을 전달해 주세요.

되돌리기

HermesPaperclip 폴더의 제거를 실행하면 설치한 것이 지워집니다. 설치 전부터 쓰던 Hermes가 있었다면 그 설정은 그대로 둡니다.
