Hermes + Paperclip 설치 안내

이 문서는 터미널을 쓰지 않는 분을 위한 안내입니다. 순서대로만 따라 하시면 됩니다.

먼저 알아두세요
  • 설치에는 인터넷이 필요하고, 10~30분 정도 걸립니다. 내려받는 양이 큽니다.
  • 관리자 암호는 한 번도 필요 없습니다. 암호를 물으면 잘못된 것입니다.
  • 진행되는 검은 창은 끝날 때까지 닫지 마세요.

방법 1. 더블클릭으로 설치 (권장)

  1. 압축 파일(HermesPaperclip-macOS.zip)의 압축을 풉니다.
  2. 설치.command 파일을 우클릭한 뒤 열기를 선택합니다.
    그냥 더블클릭하면 macOS가 “확인되지 않은 개발자”라고 막을 수 있습니다. 그때도 우클릭 → 열기로 진행하면 됩니다.
  3. “열겠습니까?”라는 창이 뜨면 열기를 누릅니다.
  4. 검은 창에서 한국어로 진행 상황이 나옵니다. Enter를 누르지 말고 기다리세요.
  5. 끝나면 브라우저가 자동으로 열리고, 대시보드가 보입니다.
  6. 홈 폴더에 HermesPaperclip 폴더가 생깁니다. 나중에 켜고 끄고 지울 때 씁니다. 처음 받은 압축 파일은 이제 지워도 됩니다.

방법 1이 막히면 — 터미널 한 줄

아래 한 줄을 복사해서 터미널(Terminal)에 붙여넣고 Enter를 누르세요. 이 방법은 macOS 경고가 뜨지 않습니다.

curl -fsSL https://github.com/giljae/hermes-paperclip-native/releases/latest/download/bootstrap.sh | bash

터미널 여는 법: Spotlight(⌘ + Space)에서 “터미널”을 검색해 실행합니다.

설치가 끝난 뒤 — AI 연결

설치만으로는 AI가 연결되지 않습니다. HermesPaperclip 폴더의 AI연결을 실행해 주세요.

  1. 추천Nous Portal로 간편 로그인 — 브라우저에서 로그인만 하면 됩니다. API 키를 따로 만들 필요가 없습니다.
  2. 내 API 키 사용 — Anthropic / OpenAI / OpenRouter 키가 이미 있는 경우.
  3. 나중에 하기 — 나중에 다시 실행할 수 있습니다.

마지막에 월 예산을 묻습니다. 정해두면 요금이 갑자기 늘어나는 것을 막을 수 있습니다 (Paperclip은 CEO에게 월 $30~50을 권장합니다).

문제가 생겼을 때

  • 창이 “확인되지 않은 개발자”라고 막을 때 — 그 파일을 우클릭 → 열기로 실행하세요.
  • 진행이 멈춘 것 같을 때 — 실제로는 내려받는 중일 수 있습니다. 30분까지 기다려 보세요.
  • 다시 시도할 때 — 설치.command를 다시 실행하면 됩니다. 이미 된 단계는 건너뜁니다.
  • 기록을 보내야 할 때 — ~/.hermes-paperclip-native/logs/ 폴더의 파일을 전달해 주세요.

되돌리기

HermesPaperclip 폴더의 제거를 실행하면 설치한 것이 지워집니다. 설치 전부터 쓰던 Hermes가 있었다면 그 설정은 그대로 둡니다.
